# Revenue Anomaly Root-Cause Investigator

## The Problem

The Revenue Ops lead at a retail company finds out about a sales drop the same way
everyone else does: someone notices it in the weekly report. By that point the drop is
typically three to seven days old, and the report says only that revenue is down — not
which category, channel, or region moved, and not why. Someone then spends the better
part of a day pulling numbers to answer a question that has already gone stale, and the
window to act on the cause has usually closed. This project closes that gap: it watches
daily revenue as it lands, separates a real drop from ordinary daily fluctuation, checks
the usual suspects — marketing spend, inventory, and outside factors — and writes up what
it found, before anyone has opened the weekly report.
